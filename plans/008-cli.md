## Deliverables
`sqlmpeg/cli.py` — argparse, `main(argv: list[str] | None = None) -> int`:
- `sqlmpeg compile QUERY.sql [--graph-only]` — prints the full command POSIX-quoted
  via `shlex.join` (it's documentation output, even on Windows), or just the
  filter_complex string with --graph-only.
  Output path placeholder `out.mp4` unless `-o` given.
- `sqlmpeg explain QUERY.sql` — `json.dumps(graph.to_dict(), indent=2)`.
- `sqlmpeg validate QUERY.sql [--json]` — exit 0 silent on success; on SqlmpegError
  exit 1, stderr one-line human message, or `--json` → `json.dumps(err.to_dict())`
  on stdout.
- `sqlmpeg run QUERY.sql -o OUT [--timeout SECS (default 600)] [-y]` — compile then
  `subprocess.run(args_list, timeout=..., capture stderr)`. No shell. Check ffmpeg
  on PATH first (`shutil.which`) → clear error if missing. On ffmpeg failure: exit
  code passthrough, last 30 lines of stderr surfaced. `-y` appends ffmpeg `-y`.
- All commands: read file (errors nicely on missing), catch SqlmpegError → formatted
  line-anchored message on stderr, exit 1. Exit 2 for usage errors (argparse default).
- QUERY may be `-` for stdin.
