# 093 — pre-1.0 fixes rolled into 0.25.0

From ROADMAP.md's immediate/contract/robustness tiers; maintainer
approved the bundle 2026-08-21.

## Code
1. `sqlmpeg/__init__.py`: `__version__` read from package metadata
   (importlib.metadata.version("sqlmpeg"), with a fallback for a
   source checkout without metadata), never hardcoded.
2. Public API: `sqlmpeg/__init__.py` exports and documents the library
   surface - `compile_sql`, `compile_commands`, `compile_table_sql`,
   `classify` (from compiler), `SqlmpegError`, `ErrorCode` (from
   errors), `emit`, `build_ffmpeg_commands` (from emit),
   `build_system_prompt` (from prompt). `__all__` lists them; the
   module docstring is the API's front page (terse). A test imports
   each from the top level.
3. `ladspa` joins the N-input table in lower.py (N->A, dynamic pads;
   no `inputs` option to emit - ffmpeg derives the count from the
   plugin, so emit_default=False and pass the streams through). Test
   hermetically against the reference registry snapshot (it must
   contain ladspa's -help options; verify; if the snapshot predates
   it, regenerate via scripts/gen_snapshot.py on this machine's
   ffmpeg and note the version line).
4. Fuzz property tightened (tests/test_fuzz.py): mutated input yields
   a compile or a SqlmpegError whose code is NOT INTERNAL. Run it at
   a generous example count locally; every INTERNAL it surfaces is a
   real bug - fix each at its source (typed rejection), with a
   regression test per find. This step runs LAST, after 092.
